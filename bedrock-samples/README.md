# Bedrock Samples

Samples for running NVIDIA models on [Amazon Bedrock](https://aws.amazon.com/bedrock/), fully managed serverless inference.

- [`nemotron-3-getting-started/`](nemotron-3-getting-started/) — Getting started with NVIDIA Nemotron 3 on Bedrock: inference, tool calling, streaming, and reasoning modes.
- [`nemotron-3-bedrock-knowledge-bases-rag/`](nemotron-3-bedrock-knowledge-bases-rag/) — End-to-end RAG with Nemotron 3 using Bedrock Knowledge Bases and Guardrails.

Each subfolder contains its own self-contained README with setup and usage instructions.
