# Agentic

Samples for building agentic and retrieval-augmented AI applications with NVIDIA on AWS, organized by AWS service. Each example folder contains its own README with setup and usage instructions.

## Amazon EKS

Self-managed deployment on [Amazon Elastic Kubernetes Service (EKS)](https://aws.amazon.com/eks/).

- [`eks/deep-research-blueprint/`](eks/deep-research-blueprint/) — Deploy the NVIDIA AI-Q Research Assistant Blueprint on EKS, with OpenSearch as the vector database.
- [`eks/rag-blueprint/`](eks/rag-blueprint/) — Deploy the NVIDIA Enterprise RAG Blueprint on EKS, with OpenSearch as the vector database.
